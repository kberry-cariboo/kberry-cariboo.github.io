CashFlow Runway

A mobile-first concept for CashFlow Budget, built from scratch rather than narrowed down from the desktop layout.

Fifteen destinations become four plus one compose action. The five Budget sub-tabs become four lenses over one timeline, so the month, account, filters and search survive the switch.

Colour is reserved for state. The substrate is ink on ruled ledger paper; the only coloured things on screen are the ones that mean something — below threshold, over target, on track, paid.

Every figure is computed in integer cents from the same seeded household, so the numbers agree wherever you look. Open Design notes under You to see where each of today's features went.
